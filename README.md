# Reality-1 · Rebuild 3

Автономный статический прототип. index.html работает без внешних библиотек.
mobile-check.html — отдельный отчёт экрана и касаний.

## Публикация
Заменить index.html, mobile-check.html и .github/workflows/deploy.yml в репозитории после проверки. В Settings → Pages выбрать GitHub Actions. Домен задаётся отдельно в Custom domain. Эта сборка не меняет DNS.

Workflow публикует две страницы и существующие каталоги assets, audio, images, docs рекурсивно. Не помещайте туда секреты или приватные документы: их содержимое станет публичным.

## Проверки
Статическая проверка структуры выполнена при генерации. JavaScript в браузере не запускался. Safari/iOS, звук и касания требуют теста на реальном устройстве. Релиз v5.4 не считается принятым.

Изменения: полноценная структура HTML; обработка неподдерживаемого dialog; управление звуком и очистка object URL; страницы диагностики; явный список публикуемых ресурсов.

Не реализованы: Supabase, аккаунты, постоянное хранение, интеллектуальный BGM, серверное восстановление. Внешних сетевых запросов код страниц не содержит.
